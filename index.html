Decalify projects decals onto any surface — taking the shape of the surface even if it's displaced.

Decalify Decalify

Decalify is a Add-on That Uses Blender 5.1's RayCast Node and projects the decal on to the surface taking the shape of the surface even if it's displaced. Currently works only in Cycles (Eevee Support maybe in furture updates)

I have Spend Past 11 Days Making Decalify And did my Best to Make it Super Easy for Beginners!

Join My Discord and Do Let me Know What Should I Add In the Next Update.

There is no Decals Asset Pack included

Features Features

Adding Decals is Easy

You can Select Target Object if you want to apply decals only on one object or Select Collection if you want to apply decals on multiple objects!
Placeing Decals is Easy too Just Click Add Decal and the Gizmo will do it's Job. Plus you can also see different actions you can perform In HUD!

Re-Place Decals

If you don't like how you placed it and want to move the decal around.
You can Select the Decal. and Click Re-Place Decal
The Gizmo will Appear and You will Also See Previous Location of the Decal you Are Re-placeing

Decal Placement Controls

The Gizmo Has a lot of Nice Features, You can do Various things like Scaling, Rotating, Normal Offset, Removing Last Placed Decal If you don't want it there. And Resetting Scale and Rotation. Once you are Done Placing Decals. You can Right Click or Press ESC that will finish the Operation!

Use Existing Decals

When you add a decal Decalify will copy the decals from where they were added into the folder where your blend file is saved. in the exact folder name as your blend file. which you also load in the Use Existing Decals Gallery by Pressing Refresh Button and you can Select from There and Add them.

Preferences

In the Preferences Tab you can Find A lot of Customization Settings. You can add your Decals Library That you want to use. There are Icon Gallery Scale and Popup Controls, And Rest are Gizmo Settings. You can Play Around with. But the Default Settings Are the Best Fine Tuned By ME
Modes Modes

There are Two Placement MODES

For Flat Surfaces

Flat Surface Mode Is for Models that have Clean and Flat Topology
It Takes Normals from the Mesh Face Which then Align the Decals Normals to match the Face Normals. So if you have Rough and Dense Topology This Mode Won't Work!

For Rough Surfaces

Rough Surface Mode is Made for Models that have Rough and Uneven Topology
This Mode Takes Normals from All The Mesh Faces below the Gizmo Preview Then Averages out the Normals Which then Align the Decal Plane Nicely Flat to the Rough Surface. HOWEVER IT IS IN EXPERIMENTAL Because IT Rotates Your Decal If you move from One Side to another

With FLAT Surface Mode on Rough Surface

As you can see I'm Using Flat Surface Mode on Rough Surface and it's Glitching Out. Because Where there is Face below The mouse it's Appling The Normals of that Face to the Decal
